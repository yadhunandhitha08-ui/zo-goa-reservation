# ZO Hotels Goa — reservation page

A static reservation page built as a design sample: the booking in full with a
line-by-line price breakdown, the booked room as an interactive photograph,
what the rate includes, distances around Candolim, recent stays, and the
options a guest has for changing the reservation.

Plain HTML, CSS and vanilla JavaScript — no frameworks, no build step.

    index.html    style.css    script.js    images/

Rates, reviews and reference numbers are illustrative.
